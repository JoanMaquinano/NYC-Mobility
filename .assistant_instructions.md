## Agent Memories

### Data context
- The `nyc_bronze.taxi_zones` table has a column named `LocationID` (mixed case: capital L, capital ID). SQL references must use backticks: `\`LocationID\``. Using lowercase `location_id` causes `UNRESOLVED_COLUMN` errors in Databricks SQL with Unity Catalog.
- The `nyc_bronze.green_taxi` table uses lowercase column names (`pu_location_id`, `do_location_id`) — these do NOT need backticks.
- The NYC-Mobility project DQ gate in `02_bronze_all_qc.sql` intentionally calls `raise_error()` when blocking checks fail. A `USER_RAISED_EXCEPTION` / `Bronze DQ gate FAILED` error means the gate is working as designed — it's catching real data issues, not a code bug.
